# 文档格式批量整改工具 · 使用说明书

> 纯前端本地运行的 Word 文档排版标准化工具：**无需注册、无需登录、文件不上传、无广告无弹窗**。
> 拖入文档 → 选择模板或自定义参数 → 一键整改 → 预览对比 → 导出 Word / PDF。
>
> 🌐 **在线直接用（推荐，什么都不用装）**：<https://guli504.github.io/doc-format-tool/>
> 把这个网址发给任何人就能用（手机、平板、别人电脑都行）；文档始终只在他自己的浏览器里处理，不会上传。
>
> 💾 **离线单文件版**：`发布/文档格式整改工具.html` —— 断网、内网、拷 U 盘都能用。

---

## 一、30 秒开始使用

1. 打开 `index.html`（双击即可，**不需要安装、不需要联网、不需要开服务器**）。
2. 把 `.docx / .doc / .rtf` 文件**拖到左侧「① 文档导入」的虚线框**里，或点「点击选择文件 / 选择文件夹」。支持一次拖多个文件批量处理。
3. 在「② 排版模板」里点一个模板（如 `大学论文`），或按需要在 ③～⑭ 里逐项调参数。
4. 点右上角 **⚡ 一键整改**，右侧立刻出现「原文档 / 整改后」分屏对比。
5. 点 **⬇ 导出 Word**（多个文件会自动打包成 zip）；需要 PDF 就点 **⬇ 导出 PDF**，在打印窗口里选择「另存为 PDF」。

> 想先看看文档有哪些毛病？点 **🔍 格式检测**，下方「排版问题清单」会列出标点混用、字体混乱、缩进不统一、行距错乱、图片注释缺失、空行过多、标题未用样式、页边距异常等问题，每条都可以单独「修复此项」，也可以点 **🛠 一键修复全部问题**。

> **要发给别人用 / 想要一个网址给大家访问？** 见 [`发布/如何分享给别人.md`](发布/如何分享给别人.md)：
> 单文件版（发微信就能用）、GitHub Pages 网址版、局域网共享三种方式，按省事程度排好了。

## 二、隐私与安全

| 事项 | 说明 |
| --- | --- |
| 是否上传文件 | **不上传**。所有解析、修改、导出都由浏览器在本机完成，页面不发起任何网络请求 |
| 是否保存文件 | **不保存**。文件只存在于当前页面内存中，关闭页面即消失 |
| 保存了哪些东西 | 只把**你自己设置的参数、自定义模板、字体库**保存在浏览器 localStorage，方便下次自动恢复 |
| 如何彻底清空 | 点「重置设置」恢复默认参数；浏览器「清除站点数据」可删除全部本地配置 |
| 网络依赖 | 依赖库（JSZip）已随包放在 `js/vendor/`，**离线也能用** |

## 四、功能逐项说明

### ① 文档导入
- 拖拽上传、点击选择文件、**选择整个文件夹**三种方式。
- 支持 `.docx`、`.doc`（旧版二进制）、`.rtf`、`.txt`、`.html`；批量导入，导入过程有进度条。
- 文件名带 `~$` 的 Word 临时文件会被自动忽略。

### ② 排版模板（5 套内置，一键套用）

| 模板 | 适用场景 | 关键参数 |
| --- | --- | --- |
| 公文标准 | 党政机关公文（GB/T 9704 思路） | 仿宋三号(16pt)、固定行距 29 磅、页边距 上3.7/下3.5/左2.8/右2.6 cm、标题黑体楷体仿宋三级 |
| 大学论文 | 毕业论文 / 学位论文 | 宋体小四(12pt)、1.5 倍行距、首行缩进 2 字符、标题黑体三/四/小四、页边距 上下2.54 左右3.17 |
| 实习报告 | 实习 / 实践报告 | 宋体小四、1.5 倍行距、标题黑体 18/14/12 加粗 |
| 日常办公 | 通知 / 方案 / 汇报 | 微软雅黑五号(10.5pt)、1.15 倍行距、段后 6 磅、无首行缩进 |
| 期刊投稿 | 学术期刊投稿 | 宋体五号(10.5pt)、单倍行距、标题居中、英文 Times New Roman |

在「自定义模板名称」里输入名字，点「保存当前参数为模板」，就能把自己的参数存成专属模板，下次一键套用；点模板右侧的 ✕ 可删除。所有模板永久保存在本机。

### ③ 页面设置（页边距）
分别设置上/下/左/右页边距（厘米），提供 4 个常用数值快捷按钮。写回文档的 `w:pgMar`，不影响纸张大小。

### ④ 文字格式
中文字体、西文字体、字号（磅，附中文号数对照：小四=12、五号=10.5、三号=16…）、字体颜色、是否加粗。
中文字体写入 `w:eastAsia`，西文字体写入 `w:ascii/w:hAnsi`，互不干扰。

### ⑤ 数字格式（中文 / 数字分离排版）
开启后，数字独立使用「正文数字 / 标题数字 / 注释数字」三套字体、字号、颜色。
实现方式是**把混排的 run 按字符类别拆分**（中文 / 数字 / 西文 / 空格 / 符号各成一段），从而真正做到「中文宋体 + 数字 Times New Roman」这类排版效果。数字可分别设置：正文数字、标题数字、注释数字、**表格数字**。

### ⑥ 表格文字格式
文档里有表格时，表格文字可以**独立于正文**设置：中文字体、西文字体、字号、颜色、是否整表加粗，还能让**表头行自动加粗**（表格第一行，或勾选了"重复标题行"的行）。

- 开关**关闭**时（默认）：表格文字跟随「④ 文字格式」的正文设置；
- 开关**打开**时：表格用自己这套格式，例如正文宋体小四、表格黑体五号；
- 勾选「同时统一表格内的行距与对齐」后才会改表格里的行距和单元格对齐；不勾选就只改字体，行距原样保留；
- 表格内不套用首行缩进，避免单元格文字被挤压；
- 表格里的数字还会额外套用「⑤ 数字格式 → 表格数字」的字体字号。

> 举例：正文用宋体小四、要求表格用黑体五号且表头加粗 —— 打开⑥的开关，中文字体选"黑体"、字号填 10.5、勾选"表头行加粗"即可。

### ⑦ 标题层级标准化
- 自动识别一、二、三级标题（含四级以上，按三级规则处理），统一字体、字号、加粗、对齐、行距、缩进。
- **智能识别**：即使文档没有套用 Word 标题样式，也能按编号识别，支持两种编号体系：
  - 章节式：`第1章` → 一级、`1.1` → 二级、`1.1.1` → 三级；
  - 汉字式（公文）：`一、` → 一级、`（一）` → 二级、`1.` → 三级。
  - 默认「自动判别」；也可在下拉框里手动指定。
- 自动区分正文与标题：以句号结尾的整句、超长段落、含图片/表格的段落不会被误判为标题。

### ⑧ 段落排版
- 行距：多倍行距 / 固定值(磅) / 最小值(磅)，三种模式。
- 段前距、段后距（磅）。
- 首行缩进 0～4 字符（默认 2 字符，同时写入 `firstLineChars` 与 `firstLine`，兼容不同版本 Word）。
- 正文对齐：两端对齐 / 左 / 居中 / 右。
- 可选：**标题不缩进**、**短句不缩进**（可设字数阈值），列表/编号段落保留自身缩进。

### ⑨ 标点符号整改
- 四种模式：智能（中文用中文标点、英文用英文标点）/ 统一全角 / 统一半角 / 仅清理乱码。
- 安全保护：小数点 `3.14`、千分位 `1,000`、时间 `12:30`、编号 `1.1.2`、网址 / 邮箱 / 文件名中的标点不会被误改。
- 引号成对智能修正（`"` → `“ ”`、`'` → `‘ ’`，英文所有格 `'` 不处理）。
- 清除乱码：替换符 `�`、零宽字符、控制字符、软连字符等。
- 合并重复标点（`！！！` → `！`）；省略号统一。
- 全角字母数字转半角（`１２３` → `123`）。

### ⑩ 空格 / 空行清理
清除段首尾空格、合并段落中间连续空格、全角空格转半角、删除空段落（可设置允许保留的连续空行数）、删除空段落中的分页符（即空白页）。

### ⑪ 图片 / 表格注释（题注）
- 自动识别「图1 / 表2 / Figure 3」这类题注，也把**紧跟在图片后面的短段落**当作题注。
- 统一题注字体、字号、颜色、行距、对齐方式、缩进。
- 可统一添加**前缀 / 后缀**（如 `图 ` 前缀、`（数据来源：…）` 后缀），已有前缀不会重复添加。
- 表格文字同样纳入处理范围（见 ⑬）。

### ⑫ 公式 / 单位保护
开启后，数学公式（OMML，含分式、根式、矩阵等）内部格式完全不动，避免公式乱码变形；含 `℃ ± ≤ ≥ × ÷ m²` 等数学/单位符号的短片段也不会被改字体。

### ⑬ 处理范围
勾选哪些区域参与整改：表格内文字、文本框内文字、页眉、页脚、批注、脚注/尾注。未勾选的区域原样保留。

### ⑭ 字体自定义库
- 内置 28 款常用中英文字体（宋体、黑体、楷体、仿宋、微软雅黑、Times New Roman 等）。
- 可**新增**自定义字体名（例如只装在公司电脑上的「方正小标宋简体」）、可**删除**不需要的、可**★ 收藏**（收藏的字体会排在所有字体下拉框最前面）。
- 「加载本地字体文件预览」可临时把 `.ttf/.otf` 注册进浏览器，让预览显示真实字形（导出的 Word 只记录字体名称，最终显示取决于打开文档的电脑是否安装该字体）。

## 六、导出说明

**导出 Word（.docx）**
- 采用「**直接改写 OOXML 部件**」的方式：只替换 `word/document.xml`（以及需要处理的页眉/页脚/批注部件），zip 内其余部件按原字节复制。
- 因此图片、公式、表格、超链接、批注、页眉页脚、域代码、编号等对象**原样保留**，不会像「转换型工具」那样丢格式。
- 文件名自动加后缀 `_已整改`；多文件导出为 `已整改文档_N个.zip`。

**导出 PDF**
- 打开打印窗口并自动调起打印，请在「目标打印机」里选择 *另存为 PDF*（或 *Microsoft Print to PDF*）。
- 打印样式已按页面尺寸与页边距设置好，版式与预览一致；建议在打印设置里把「页边距」设为**无**、「缩放」设为**默认/100%**。

## 七、常见问题

**Q1：为什么旧版 `.doc` 只能提取文字？**
`.doc` 是 1990 年代的 OLE 复合二进制格式（不是 zip+XML），浏览器端无法无损改写其中的格式信息。工具会解析它的分片表把文字完整取出来，合成为标准 `.docx`，之后所有整改与导出都以 `.docx` 进行。文中的图片、公式等二进制对象无法读取，会在文档中留下文字位置（图片处显示 `[图片]` 占位）。**建议：能用 Word 另存为 `.docx` 的，优先用 `.docx`。**

**Q2：公式会被改乱吗？**
不会。默认开启「公式 / 单位保护」，公式内部的字体、字号、颜色一律不动。

**Q3：预览里的字体和最终 Word 不一样？**
预览用的是**你这台电脑已安装的字体**。如果文档指定了本机没有的字体，浏览器会用相近字体代替显示；但导出的 `.docx` 里记录的字体名称是正确的，在装有该字体的电脑上打开就是正确效果。

**Q4：整改后文字变少了？**
多半是「空行清理」删掉了空段落，或「短句不缩进」等设置生效。可以在「⑩ 空格/空行清理」里把「允许保留的连续空行」设为 1，或临时关闭该区块开关，预览会立刻更新。

**Q5：会影响批注和页眉页脚吗？**
默认只处理正文；需要时在「⑬ 处理范围」里勾选批注 / 页眉 / 页脚。若某文档的批注不需要改动，保持不勾选即可。

**Q6：一直点「一键整改」会重复叠加吗？**
不会。每次整改都是**从你导入的原始文件重新计算**，参数怎么改都可反复重来（已通过「幂等性」自动化测试验证）。

**Q7：导出 PDF 没反应？**
浏览器可能拦截了弹出窗口。请允许本站点弹出窗口后重试。

**整改流水线（每次都是原始文件 → 新文件）**

```
读取 zip 中的 document.xml
   → 清理空行/空白页 → 清理空格
   → 标点整改（字符级数组：段落语言判定 + 上下文保护 + 引号配对）
   → 中/数字/西文 run 拆分与字体写入（跳过公式与单位片段）
   → 段落属性：行距 / 段前段后 / 首行缩进 / 对齐
   → 标题层级识别与统一样式（样式判定 + 编号启发式）
   → 图片题注格式与前后缀
   → 页边距（sectPr/pgMar）
   → 序列化 XML，替换部件，重新打包 zip → 下载
```

**关键实现点**
- 所有 XML 元素按 OOXML schema 规定的顺序插入（`w:rPr` 必为 run 首子元素、`w:pPr` 必为段落首子元素），保证 Word 正常识别；
- 字号用半点、行距用二十分之一磅、页边距用缇（twip）换算，与 Word 内码一致；
- 首行缩进同时写 `firstLineChars` 与 `firstLine`，对 WPS / Word / LibreOffice 都生效。
