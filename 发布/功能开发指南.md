## 一、先记住：功能是"五层"的

一个功能从设置到生效，贯穿 5 个地方。加功能 = 按需动这几层：

```
┌─────────────────────────────────────────────────────────┐
│ 1. 参数层  js\constants.js     每个设置项在这里定义默认值 │
│ 2. 引擎层  js\engine.js        真正干活的逻辑在这里       │
│ 3. 界面层  index.html + js\app.js  设置面板 / 按钮 / 预览 │
│ 4. 知识层  js\knowledge.js     规范词条 / 单位词典（可选）│
│ 5. 测试层  test\engine-test.html + test\ui-demo.html     │
└─────────────────────────────────────────────────────────┘
改完 → 双击 发布\重新打包.bat → 生效；要上线再跑 更新线上网站.ps1。
```

**改功能**：找到对应层改对应行。
**加功能**：通常五层都要碰，但每层只加几行 —— 照下面示例抄。

## 二、完整示例：新增一个模板（最入门、零风险）

我刚刚真的加了一个模板「科研论文 · 数字单位规范」，就是照这个套路做的：

### 第 1 步（参数层）：在 `js\constants.js` 的 `TEMPLATES` 数组末尾加一项

```js
{
  id: 'research',                        // 唯一 id
  name: '科研论文 · 数字单位规范',        // 界面显示的名字
  desc: '理工科论文/申报书：宋体五号 + Times、1.5 倍行距、三线表、数字与单位规范自动启用',
  params: {
    body: { enabled: true, cnFont: '宋体', latinFont: 'Times New Roman', size: 10.5 },
    paragraph: { enabled: true, lineMode: 'multiple', lineValue: 1.5, indentChars: 2, align: 'justify' },
    table: { enabled: true, borderStyle: 'threeLine', headerBold: true, sizeFollow: true },
    unit: { enabled: true, fixSpelling: true, spaceNumber: true },   // ★ 新功能：数字与单位规范
    // …其余项照抄现有的模板，按需改
  }
}
```

### 第 2 步（界面层）：几乎不用动

模板区是**自动渲染**的：`js\app.js` 的 `renderTemplates()` 遍历 `TEMPLATES` 生成卡片，所以加了数组项，界面立刻多一张卡。只改了一处静态文字：`index.html` 里「② 排版模板 <span>5 套内置</span>」改成「6 套内置」。

### 第 3 步（测试层）：同步断言

`test\ui-demo.html` 里原来写死 `模板卡片 .length === 5`，改成 `=== 6`。防止以后加模板忘了数。

### 第 4 步：打包上线

```
双击 发布\重新打包.bat   →  本地生效
右键 发布\更新线上网站.ps1 → 用 PowerShell 运行  →  线上生效（约 1 分钟）
```

**效果**：界面上「② 排版模板」多了「科研论文 · 数字单位规范」，点一下，正文、行距、表格、数字单位规范全部套好。

> 模板 = "一组参数的快照"。想改任何模板，直接改对应 `params` 里的值即可。

## 三、进阶示例：给"数字与单位规范"加一条规则

知识库引擎在 `js\engine.js` 的 `applyUnitFormat` / `fixUnitString` 里。想加一条新规则（比如"把 5-10 这种数字范围统一成 5~10"）：

### 第 1 步（参数层）：`js\constants.js` 的 `unit` 里加开关

```js
unit: {
  ...,
  dashTilde: true      // ★ 新增：数字范围连接号统一（5-10 → 5~10）
}
```

### 第 2 步（引擎层）：`js\engine.js` 的 `fixUnitString` 里加一条

照着已有规则（⑨⑩ 那几段）的写法：

```js
// ⑩ 数字范围连接号统一
if (o.dashTilde) {
  out = out.replace(/(\d)-(\d)/g, function (m, a, b) {
    hits.dash++;
    return a + '~' + b;          // 注意：要排除日期 2026-10 这种，见下方"防坑"
  });
}
```

- `hits` 是统计对象，用来在完成提示里显示"改了 N 处"。新加的键记得在 `newUnitHits()` 里补上（`dash: 0`），并在 `unitHitsTotal()` 里加上。
- `report.unitFixed` 会自动汇总，不用额外处理。

### 第 3 步（界面层）：`index.html` 的「⑰ 数字与单位规范」里加一个开关

```html
<label class="inline"><input type="checkbox" data-param="unit.dashTilde" data-type="bool"> 数字范围连接号统一：5-10 → 5~10</label>
```

`data-param="unit.dashTilde"` 这一行就够 —— `app.js` 的 `collectParams` / `applyParams` 会自动读取和回填，**不用改 JS**。这是这个项目最省事的地方：界面控件和数据自动双向绑定。

### 第 4 步（知识层，可选）：`js\knowledge.js` 里补一条规范条目

在对应分类的 `items` 里加：

```js
{ id: 'ma-6', level: 'medium', text: '数字范围连接号统一：中文用 <code>~</code>，英文用 <code>–</code>，不要用半角连字符 -。',
  ok: ['5~10 mg'], bad: ['5-10 mg'], params: { 'unit.dashTilde': true } }
```

这样「📚 规范库」里也能搜到，还能一键把开关点开。

### 第 5 步（测试层）：`test\engine-test.html` 加断言

在 `unitCases` 数组里加一行：

```js
['5-10 mg', '5~10 mg'],
```

### 第 6 步：打包上线（同上）

## 四、改"检测功能"（格式检测报问题）

检测逻辑在 `js\engine.js` 的 `analyze()` 里，结尾用 `add({...})` 注册一条问题：

```js
add({
  id: 'dash_range',          // 唯一 id
  category: '数字与单位',     // 问题清单里的分类
  level: 'low',              // high / medium / low / info
  title: '数字范围用了连字符 -',
  count: n,                  // 出现次数
  detail: '建议统一为 ~ 或 –。',
  samples: [...],            // 示例文本（点问题可定位到预览）
  fix: { 'unit.dashTilde': true }   // "修复此项"按钮会写入这些参数
});
```

有 `fix` 字段的问题，界面里会出现「修复此项」按钮，一键套用对应设置。

## 五、新功能 = 新参数组（更复杂时）

如果功能有多个设置项，就按 `unit` 的样子加一整组：

```js
/* 在 DEFAULT_PARAMS 里加 */
myfeature: {
  enabled: false,
  mode: 'auto',
  amount: 2
}
```

界面照「⑰」的样子加一个 `<details class="sec" data-cat="...">` 折叠卡片，里面全是 `data-param="myfeature.xxx"` 的控件；引擎在 `transformPart` 主循环里加一步调用（参考 `applyUnitFormat(para, ep, report, scriptMap)` 那行怎么插入的）。

## 六、防坑清单（改代码必读）

1. **只改源码，别改成品**：`发布\文档格式整改工具.html` 是打包产物，一打包就被覆盖。
2. **编码**：`.js/.css/.html` 用 UTF-8；`.bat` 用 GBK；`.ps1` 用 UTF-8 带 BOM。
3. **JS 里不能出现 `</script`** 字样，否则打包报错。
4. **正则别写错转义**：JS 正则字面量里用 `\u`（如 `/\u2264/`），不要写 `\\u`（那是字符串里才用的）—— 这个坑踩过，会把数字当符号处理。
5. **改完跑测试**：浏览器打开 `test\engine-test.html`，必须"全部通过"。
6. **升版本号**：`js\constants.js` 顶部 `VERSION`（如 `1.2.0`→`1.3.0`），同步把 `index.html` 里的 `?v=120` 改成 `?v=130`，否则浏览器缓存会卡在旧版。
7. **改前备份**：把 `doc-format-tool` 文件夹复制一份。
8. **改规则先想误伤**：文本类规则要防"把对的改错"，参考知识库词典里我删掉的那些歧义词条（Mg 镁、BP 血压…）。拿不准就默认关闭，让用户显式开启。
