# VS Code 使用教程（在这个项目里改代码）

> 前提：你已经装好 VS Code。
> 本教程从"双击打开"讲到"改完上线"，全程跟着点就行。

---

## 〇、打开项目（二选一）

**方式 A（推荐）**：双击项目根目录下的 **`doc-format-tool.code-workspace`**
→ 会弹出"选择应用"→ 选 VS Code（勾选"始终使用"）→ 整个项目就在 VS Code 里打开了。

**方式 B**：打开 VS Code → 菜单 **文件 → 打开文件夹** → 选中 `D:\deepseek harness\doc-format-tool` 文件夹 → 确定。

打开后左侧「资源管理器」里应该能看到：
```
doc-format-tool
├─ .vscode\        （我配好的"一键打包"任务，别删）
├─ build\ css\ js\ test\ 发布\
├─ index.html
├─ doc-format-tool.code-workspace
└─ README.md
```

## 一、先装两个推荐扩展（让开发更顺）

按 `Ctrl+Shift+X` 打开扩展商店，搜索安装：

| 扩展 | 作用 |
| --- | --- |
| **Live Server**（ritwickdey.LiveServer） | 实时预览：改代码保存后浏览器自动刷新，不用打包 |
| **中文（简体）语言包**（ms-ceintl.vscode-language-pack-zh-hans） | 界面变中文 |

装完右下角会提示重启 VS Code，重启即可。

## 二、认识界面（四个地方）

```
┌─────────────────────────────────────────────────────┐
│ ① 顶栏：菜单 / 文件 / 编辑 / 视图…                     │
├──────────────┬──────────────────────────────────────┤
│ ② 左侧 资源管理器 │  ③ 中间 编辑器（改代码的地方）          │
│  (点文件打开)    │                                      │
│               │                                      │
├──────────────┴──────────────────────────────────────┤
│ ④ 底部状态栏：右下角显示编码（UTF-8）、行号；中间有"终端"按钮 │
└─────────────────────────────────────────────────────┘
```

快捷键：
- `Ctrl+P` 快速打开文件（输入文件名跳转）
- `Ctrl+F` 当前文件内搜索（如搜"科研论文"）
- `Ctrl+Shift+F` 整个项目搜索
- `Ctrl+Z` 撤销 / `Ctrl+Y` 重做
- `Ctrl+S` 保存

## 三、改代码的完整循环（重点）

**场景**：把顶栏标题改成你自己的名字。

### 第 1 步：定位
左侧点开 `index.html` → 按 `Ctrl+F` → 输入 `文档格式批量整改工具` → 找到：
```html
<h1>文档格式批量整改工具</h1>
```

### 第 2 步：修改
改成：
```html
<h1>我的文档整改工具</h1>
```

### 第 3 步：保存
`Ctrl+S`。注意右下角编码是 **UTF-8**（不是 GBK/ANSI）。

### 第 4 步：看效果（两条路）

**A. 实时预览（推荐开发时）**：
1. 在左侧 `index.html` 上**右键 → Open with Live Server**
2. 浏览器自动打开 `http://127.0.0.1:8899/`
3. 回到 VS Code 改代码 → `Ctrl+S` → 浏览器**自动刷新**就能看到改动
   （这是"多文件版"预览，改 `js/` `css/` `index.html` 都实时生效，**不需要打包**）

**B. 打包成单文件版（给别人用 / 上线）**：
按 `Ctrl+Shift+B` → 选 **「重新打包（生成单文件版）」** → 终端显示"生成完成"
→ 成品 `发布\文档格式整改工具.html` 已更新 → 双击它就能用。

## 四、一键打包 / 推送（我配好的任务）

按 `Ctrl+Shift+B`（或 终端 → 运行生成任务），会看到三个任务：

| 任务 | 干什么 | 什么时候用 |
| --- | --- | --- |
| **重新打包（生成单文件版）** | 合成 `发布\文档格式整改工具.html` | 每次改完源码、要给别人用之前 |
| **打开成品** | 用默认浏览器打开打包好的单文件 | 快速验证打包结果 |
| **推送线上（更新线上网站）** | 同步并推到 GitHub，约 1 分钟生效 | 想让网上版本也更新时 |

> 也可以随时在 VS Code 里按 `Ctrl+\`` 打开**终端**，手动敲：
> ```
> 发布\重新打包.bat        ← 重新打包
> ```

## 五、改"参数"的例子（最常用）

想改默认字号：左侧点开 `js\constants.js` → `Ctrl+F` 搜 `size: 12` → 找到 `body:` 那段：
```js
body: { enabled: true, cnFont: '宋体', latinFont: 'Times New Roman', size: 12, ... },
```
把 `size: 12` 改成 `size: 14` → `Ctrl+S` → Live Server 刷新预览 / 或 Ctrl+Shift+B 打包。

> `js\constants.js` 里几乎存着所有"设置项默认值"，改这里 = 改工具的默认行为。
> 新增功能看 `发布\功能开发指南.md`。

## 六、常见问题

**Q：打开 .code-workspace 时没反应 / 没找到 VS Code？**
手动方式：先打开 VS Code → 文件 → 打开文件夹 → 选项目根目录；再文件 → 将工作区另存为 → 也能生成自己的 workspace。

**Q：保存后中文变乱码？**
右下角把编码改成 **UTF-8**（点一下编码名 → 选择"通过编码重新打开/保存"→ UTF-8）。
`index.html`、`js\*`、`css\*` 一律 UTF-8；`*.bat` 是 GBK（别动它）；`*.ps1` 是 UTF-8 带 BOM。

**Q：Ctrl+Shift+B 报"找不到 node"？**
我用的是内置 Node 的绝对路径，正常不会报。若换了电脑：装 Node.js（https://nodejs.org），并把 `.vscode\tasks.json` 里的命令改成 `node`。

**Q：改坏了怎么恢复？**
- 单文件：`Ctrl+Z` 撤销。
- 整个文件：项目根目录复制一份备份；或者用 VS Code 左侧"源代码管理"里看改动并还原。

**Q：想在手机/另一台电脑上看效果？**
打包成单文件版（Ctrl+Shift+B）→ 把 `发布\文档格式整改工具.html` 发给对方，双击即用，无需任何安装。
