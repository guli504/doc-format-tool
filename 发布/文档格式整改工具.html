使用说明书

0. 界面怎么用（v1.1 新版）

分类筛选：左侧顶部一排胶囊按钮（文字 / 数字 / 段落 / 标点 / 图片注释 / 角标 / 表格 / 页面 / 保护与范围）可一键只看某一类设置，点“全部”恢复。
面板折叠：工具栏左侧的「☰ 设置」可收起/展开参数面板；窗口变窄时它会自动变成抽屉，点遮罩关闭。
分屏对比：分屏时中间有一条分割线，按住左右拖动即可调整左右比例（双击复位 50%）。
问题定位：点「格式检测」后，在问题清单里点击任意一条，预览区会自动滚动并高亮对应段落。
实时联动：调字体、行距、缩进等参数时右侧预览会立即刷新，不用反复点确认。
一键整改：点击后左栏会显示「解析 → 整改 → 渲染」三步进度，完成后提示“本次修改了 N 处”。

0.1 数字与单位规范知识库（v1.2 新增）

工具栏的「📚 规范库」内置了《实验论文数字 & 单位格式规范》校订版：8 大类 / 54 条规范 / 119 个单位 / 164 种常见错误写法，可搜索、可一键套用参数。左侧「⑰ 数字与单位规范」把这套规范变成自动整改：ul/KD/ml → μL/kDa/mL、10μL → 10 μL、95 % → 95%、P<0.05 → P < 0.05、37℃ → 37 °C 等。默认关闭，理工科论文与申报书建议开启。

1. 导入文档

把 .docx / .doc / .rtf 文件拖到左侧“文档导入”区域，或点击“点击选择文件”。支持一次选择多个文件批量处理。所有解析都在本机浏览器完成，文件不会上传。

2. 选择模板或自定义参数

左侧 ①～⑯ 是全部设置项：页面边距、文字格式、数字格式、表格格式标准化、标题层级、段落排版、标点、空格空行、图片/表格题注、公式保护、角标、整改范围、处理范围、字体库。点击②中的内置模板（公文标准 / 大学论文 / 实习报告 / 日常办公 / 期刊投稿）可一键套用；表格还可以在「⑥」里单独套用 3 套表格模板。

3. 表格、角标、范围三个专项

表格：「⑥ 表格格式标准化」可一键统一边框线型（单线 / 双线 / 三线表）、表头加粗与底色、行高、跨页重复表头、数字小数点对齐、超出页宽自动缩放；表格文字与正文互不干扰，且只改样式不动数据与合并单元格。
角标：「⑬ 角标」自动识别上标下标（H₂O、x²、cm³、[1] 等），角标用独立字号，不会被正文改大变形；识别不到的可以填进“手动修正”强制设为上标。
范围：「⑭ 整改范围」默认自动豁免封面页与目录页，也可以只整改指定页 / 指定分节、豁免参考文献与附录。被排除的区域连标点、空格、页边距都不会改；原文档预览里会用黄色斜纹高亮显示这些区域。

4. 一键整改并预览

点击右上“⚡ 一键整改”，右侧会同时显示“原文档”和“整改后”两页，可切换“原文档 / 分屏对比 / 整改后”三种视图，用缩放调节显示比例。

4. 格式检测与一键修复

“格式检测”会扫描标点混用、字体混乱、缩进不统一、行距错乱、图片注释缺失、空行过多、标题未用样式、页边距异常等问题，并列出问题清单；点“一键修复全部问题”会自动打开对应参数并重新整改。

5. 导出

“导出 Word”生成整改后的 .docx（保留图片、公式、批注、表格、超链接等全部对象；多文件会打包为 zip）。
“导出 PDF”会打开打印窗口，选择“另存为 PDF”即可，版式与预览一致。

6. 撤销 / 重做 / 重置

每个参数改动都会记录历史，可逐步撤销与重做（快捷键 Ctrl+Z / Ctrl+Y）；“重置设置”恢复出厂参数。参数、模板、字体库都会自动保存在本机浏览器中，下次打开自动恢复。

7. 注意事项

  • 旧版 .doc 是二进制格式，浏览器只能提取其中的文字（图片、公式等二进制对象无法读取），导出时会转换为 .docx。
  • 公式（OMML）默认被保护，不参与字体整改，因此不会被改乱。
  • 预览使用本机字体渲染；若某字体未安装，会用相近字体代替显示，但导出的文档中字体名称是正确的。
