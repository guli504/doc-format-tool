## 一、先搞清楚：源码 ≠ 成品

| 是 | 说明 |
| --- | --- |
| **源码** | `D:\deepseek harness\doc-format-tool\` 下的 `index.html`、`js\`、`css\` —— 你要改的是这些 |
| **成品** | `发布\文档格式整改工具.html` —— 由打包脚本生成的"单文件版"，**不要直接改它**，改完会被覆盖 |
| **线上** | GitHub Pages：`https://guli504.github.io/doc-format-tool/` —— 由 `发布\更新线上网站.ps1` 推送 |

一句话：**改源码 → 双击「重新打包.bat」→ 本地生效；再跑「更新线上网站.ps1」→ 网上生效。**

## 二、目录结构（每个文件干什么）

```
doc-format-tool\

├─ css\app.css         全部样式（配色 / 布局 / 动画 / 纸面效果）

│  ├─ engine.js        ③ 核心引擎：解析 docx / 整改逻辑 / 格式检测 / 范围保护
│  ├─ ooxml.js         ④ 读取 & 写回 docx（OOXML 底层）
│  ├─ render.js        ⑤ 把 docx 渲染成网页预览
│  ├─ legacy-doc.js    ⑥ 兼容旧版 .doc / RTF / 纯文本
│  ├─ store.js         ⑦ 参数在浏览器里的保存 / 恢复
│  └─ app.js           ⑧ 界面交互控制器（按钮、预览联动、上传、导出）
├─ test\               自测页面与脚本（改完跑一遍，防止改坏）
├─ build\build-single.js   打包脚本（把源码合成一个 HTML）
└─ 发布\
   ├─ 文档格式整改工具.html   成品单文件版（双击即用，可发给别人）
   ├─ 重新打包.bat           ★改完源码后双击它，重新生成成品
   ├─ 更新线上网站.ps1        ★把改动推到 GitHub，网上生效
   ├─ 启动工具.bat           双击打开成品
   └─ 网站版\                线上同款文件（推送时自动同步，一般不用手改）
```

## 三、三步走：改 → 打包 → 上线

### 第 1 步：改源码
用任意文本编辑器打开（推荐 **VS Code**，或记事本也行，但保存别改编码）。

### 第 2 步：重新打包（本地生效）
双击 **`发布\重新打包.bat`**，看到"打包完成"即可。
之后：
- 双击 `发布\启动工具.bat` 或打开 `发布\文档格式整改工具.html` 就能看到你的改动。

### 第 3 步：上线（网上生效，可选）
右键 `发布\更新线上网站.ps1` →「使用 PowerShell 运行」。
脚本会自动：同步文件 → `git` 提交 → 推送到 GitHub → 大约 1 分钟后网上生效。
（注意：**先运行一次 `一键推送到GitHub.ps1` 完成登录**，之后就不用了。）

### 常见例子

**例子 1：给知识库加一个单位（比如"兆碱基 Mb"）**
打开 `js\knowledge.js`，找到 `UNITS` 数组，在末尾加一行：
```js
{ canon: 'Mb', alts: ['MB', 'Mbp'], kind: 'bio' },   // 兆碱基
```
保存 → 双击 `重新打包.bat` → 完成。

**例子 2：把正文默认字号改成 12 磅（小四）**
打开 `js\constants.js`，搜 `body:`，把 `size: 12`（已是 12）改或确认，或把模板里的字号改了：
```js
body: { cnFont: '宋体', latinFont: 'Times New Roman', size: 12, ... },
```

**例子 3：换主题色（比如改成绿色）**
打开 `css\app.css`，改顶部 `:root` 里的 `--brand: #2563EB;`，例如 `--brand: #0F766E;`。

**例子 4：改顶栏标题**
打开 `index.html`，搜 `<h1>文档格式批量整改工具</h1>`，改成你自己的名字。

改 `js\` 后，建议跑一遍自测：

打开 test\engine-test.html   （在浏览器里打开，看是不是"全部通过"）

## 六、注意事项（踩过的坑）

1. **不要直接改 `发布\文档格式整改工具.html`** —— 它是打包产物，一重新打包就被覆盖。
2. **保存编码**：`.js` / `.css` / `.html` / `.md` 一律 **UTF-8**；
   `.bat` 用 **GBK/ANSI**（中文才不会乱码）；`.ps1` 用 **UTF-8 带 BOM**。
3. **打包脚本要求**：任何 JS 里不能出现 `</script` 这几个字符（会提前结束脚本），否则打包报错。极少数情况（比如字符串里写到了）需要改写法。
4. **改动大时备份**：动手前把整个 `doc-format-tool` 文件夹复制一份。
5. **上线前先本地看**：先双击成品确认没问题，再推线上，避免把坏的推到网上。
6. **版本号**：如果改了功能，顺手把 `js\constants.js` 顶部的 `VERSION` 升一下（如 `'1.2.0'` → `'1.3.0'`），并把 `index.html` 里的 `?v=120` 改成 `?v=130` —— 这样别人刷新才会加载新版本，不会被浏览器缓存卡住。

## 七、常见问题

**Q：找不到 `D:\deepseek harness\doc-format-tool` 在哪？**
- 在资源管理器地址栏直接粘贴这个路径回车；
- 或者打开任意文件夹，在地址栏输入 `D:\deepseek harness` 回车，里面就有 `doc-format-tool`。
- 注意：是 `D 盘`（不是 C 盘），路径里有**空格**（"deepseek harness"），别打错。

**Q：没有 VS Code，记事本可以吗？**
可以。右键文件 →「打开方式」→「记事本」。但改完保存时注意别动编码（保持默认）。

**Q：我只想要成品，不碰代码，行吗？**
行。`发布\文档格式整改工具.html` 双击直接用；`启动工具.bat` 是它的快捷启动。
