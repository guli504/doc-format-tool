  1 [                     ] 
  2 [                     ] 一、空格规则
  3 [                     ] 除下文3类特殊符号外，其余单位、参数均遵循：数字 + 空格 + 内容
  4 [                     ] 
  5 [                     ] 1.数字与内容必须加空格
  6 [                     ] 
  7 [                     ] 时间：4 h、12 min、30 s
  8 [                     ] 体积：10 μL、2 mL、500 mL
  9 [                     ] 质量/浓度：5 ng/μL、0.2 μmol/L
 10 [                     ] 转速/离心力：12000 rpm、10000 g
 11 [                     ] 拷贝数/滴度：10¹⁰ copies/μL、10⁶ TCID₅₀/mL
 12 [                     ] 分子量：15 kDa、43 kDa
 13 [                     ] 稀释/倍数：10 倍、1:100 稀释
 14 [                     ] 实验参数：MOI = 0.5、pH 7.4
 15 [                     ]  
 16 [                     ] 2. 数字与内容无需加空格（仅3类）
 17 [                     ] 
 18 [                     ] 数字与符号直接相连，中间不空格：
 19 [                     ] 百分号 %：95%、0.05%
 20 [                     ] 角度符号 °、′、″：37°、45°30′、10″
 21 [                     ]  
 22 [                     ] 温度 ℃/°C（特别说明）
 23 [                     ] 有空格和没有空格二选一，全文格式统一，禁止混用
 24 [                     ] 主流期刊：37 ℃（数字与符号间加空格）
 25 [                     ] 部分格式：37℃（无空格）
 26 [                     ]  
 27 [                     ] 二、单位书写规范（大小写/字符）
 28 [                     ] 1.分子量：kDa（k小写、D大写、a小写）
 29 [                     ] 2.体积单位：用希腊字母 μL，禁止写为 uL
 30 [                     ] 3.温度符号：优先使用 °C（C大写）
 31 [                     ]  
 32 [                     ] 三、数学符号格式
 33 [                     ] ×、=、<、> 符号前后均加空格：
 34 [                     ] 1.乘号：3 × 10¹⁰
 35 [                     ] 2.等号：y = -3.2413x + 42.927
 36 [                     ] 3.不等号：P < 0.05、R² > 0.9959
 37 [                     ]  
 38 [                     ] 四、英文缩写格式
 39 [                     ] 1.缩写 + 数字：中间加空格 → MOI 0.5
 40 [                     ] 2.缩写 + 中文：中间加空格 → RT-PCR 产物
 41 [                     ] 3.常规单位缩写（h、min、μL等）：仅与前方数字加空格
 42 [                     ] 
 43 [                     ] 五、文字格式要求
 44 [                     ] 英文：Times New Roman
 45 [                     ] 中文：宋体 五号（论文）
 46 [                     ] 宋体/仿宋_GB2312 小四（申报书）
 47 [                     ] 宋体 小四 加粗（申报书插入图片的注释）
 48 [                     ] 
 49 [                     ] 六、语法问题
 50 [                     ] 中译英后可能会有一些语法错误的问题，需要注意。
 51 [                     ] 
 52 [                     ] 七、文献引用
 53 [                     ] 问题主要存在与申报书书写上面：
